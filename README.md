# Copperpot Bowls: copperpot-web

> **Fictional company.** Copperpot Bowls is a fictional company. This repository, its history and its data were generated by WWT Digital to demonstrate the Agentic Readiness Scorecard. No real company, person or system is behind it.

Copperpot Bowls web ordering storefront and in-store kiosk mode (Next.js). Fictional demonstration estate.

---

## Run it locally

```bash
npm install
npm run dev
```

The storefront talks to the commerce API; point it at a running one.

## Tests

```bash
npm test
```

## Deploys

The managed host builds `main` and serves it; previews come from branches. Releases are tagged `v*`.
